Research protocol brief · evidence before modeling

Weak supervision under an image-only constraint.

A methods-first framing for studying twelve image-derived knee MRI abnormalities when direct expert labels are scarce, reports are imperfect supervision, and acquisition structure can create leakage.

Study question
Among knee MRI examinations, can an image-only multi-label learning system identify twelve abnormalities when direct expert labels are available for only a small validation partition and the remaining exams require report-derived weak supervision?
This is a methodological study—not a clinical diagnostic validation or clinical-utility study.

Data and label provenance

4,407examinations
58complete expert-label rows
4,349training-eligible, unknown-label exams
24measured acquisition-proxy groups

The 58 complete rows reproduce all twelve known positive counts and are reserved for validation. The remaining exams are not confirmed negatives. Reports are training-time weak-supervision material; an external LLM produces probabilities, those probabilities are evaluated against the expert partition, and any downstream inference path uses images only.

No deterministic keyword, section, or negation extractor is assumed: the verified reports contain direct report-versus-label reversals.

Canonical image input contract

Routing uses only verified plane, fluid-sensitivity, and fat-suppression flags. A missing series is not a negative finding, so every slot has a presence mask.

Validation design

Acquisition-aware grouping

The grouping variable is a measured proxy, not a confirmed institution identifier. It combines available DICOM and report-derived signals. The audit produced 24 groups and 9 deterministic residual merges.

Five training-eligible folds contain 869, 865, 870, 880, and 865 exams. The 58 expert exams remain auditable but are excluded from training folds. No proxy group crosses folds.

Prespecified weak-label evaluation

  • Per-label ROC-AUC with seeded 1,000-resample 95% bootstrap intervals.
  • Macro-AUC and positive-rate bias.
  • Threshold metrics labeled optimistic same-sample upper bounds.
  • Parse failures remain NaN, never 0.5.

There are only 9–35 expert positives per label, so small AUC differences are not automatically meaningful.

Evidence-preserving workflow

train.csv reports ── external LLM ──> probability-valued weak labels │ train_series.csv ── metadata routing ──> four canonical image slots │ DICOM ── lazy per-exam load ──> normalize / sample / resize ──> image-only analysis site proxies ── grouped folds ──> leakage-aware evaluation presence masks ────────────────> explicit sequence missingness

Interpretation boundaries

Supported now

  • Schema and label counts are internally consistent.
  • Lazy metadata access read 4,407 exams with zero unreadable exams.
  • Canonical sequence availability is nonuniform and measurable.
  • Unknown labels and missing sequences are explicitly represented.

Not established

  • Diagnostic accuracy, calibration, or clinical utility.
  • External validity beyond this competition cohort.
  • That report-derived soft labels improve image-model performance.
  • That the site proxy captures all acquisition dependence.
  • Suitability or safety for clinical use.

Limitations and next gates

  1. Complete soft-label agreement analysis on all 58 expert examinations.
  2. Test the loader on a 20–50 examination local subset, including missing and malformed series.
  3. Verify cache reproducibility, memory use, and fold isolation.
  4. Review the competition labeling guideline before clinical interpretation.
  5. Only then choose a model framework and report downstream results with uncertainty and the limitations above.
The repository currently implements verified loading, lazy DICOM access, canonical routing, preprocessing, caching, explicit masks, external soft-label validation, and grouped folds. Architectures, training loops, benchmark claims, inference, and submission generation remain out of scope.
